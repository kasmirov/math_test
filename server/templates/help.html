Инструкция по использованию MathTest

⚡ Быстрый старт

  1. Перейдите на главную страницу и нажмите «Начать тест».
  2. Вы можете работать анонимно или создать профиль (рекомендуется для сохранения статистики).
  3. Выберите темы: сложение-вычитание, умножение, деление или многие другие.
  4. Решайте примеры, вводите ответы. После завершения увидите результат.
ℹ️ Примечание: Если вы не создадите профиль, история тестов не сохранится. Соответственно функционал просмотра статистики и работы над ошибками будет недоступен. Для полноценного использования создайте профиль через меню.

👤 Создание и настройка профиля

Профиль позволяет вести персональную статистику и настраивать параметры тестов.

  • Нажмите на иконку пользователя или перейдите в раздел «Аккаунт».
  • Выберите «Создать новый профиль», укажите имя.
  • При создании или позже (через редактирование) можно задать:
    • Количество вопросов в тесте (по умолчанию 10).
    • Лимит времени на весь тест или на один вопрос.
    • Диапазон чисел (например, от 1 до 20).

Если лимиты не заданы, используются значения по умолчанию. Профилей может быть несколько (например, для разных детей).

⚙️ Настройка теста

На главной странице приложения откройте меню «Настройки» (или «Settings»). В панели вы сможете:

  • Выбрать тему: сложение, вычитание, умножение, деление или комбинированный режим.
  • Указать сложность: например, только таблица умножения или двузначные числа.
  • Загрузить готовый тест из YAML-файла (см. раздел «Свои тесты»).

📊 Статистика и работа над ошибками

После каждого теста вы можете просмотреть подробный отчёт:

  • Количество правильных и неправильных ответов.
  • Время, затраченное на каждый вопрос.
  • Общий процент успеха.

Работа над ошибками: в разделе статистики напротив каждого теста есть кнопка «Повторить ошибки». При её нажатии генерируется новый тест, состоящий только из тех примеров, которые были решены неверно. Это помогает закрепить материал.

📁 Использование готовых тестов (YAML)

Вы можете создавать собственные наборы заданий в формате YAML. Пример структуры:

- question: "2 + 2"
  answer: 4
- question: "3 * 3"
  answer: 9
- question: "15 - 7"
  answer: 8

📐 Пример с формулами (LaTeX)

Если в вопросе или ответе нужно отобразить математическое выражение, используйте LaTeX-разметку внутри двойных кавычек. Обратные слеши необходимо экранировать (удваивать). При рендеринге формулы будут выглядеть красиво:

- question: "Решите уравнение: $\\frac{2x + 4}{5} = \\sqrt[3]{8}$"
  answer: 3
- question: "Вычислите: $\\left(\\frac{1}{2} + \\frac{3}{4}\\right) \\cdot 8$"
  answer: 10

Пример отображения LaTeX:

  • Решите уравнение: \(\frac{2x + 4}{5} = \sqrt[3]{8}\)
  • Вычислите: \(\left(\frac{1}{2} + \frac{3}{4}\right) \cdot 8\)

Вы можете сделать PR на github, чтобы сделать этот тест доступным для всех.

Также учитель может загрузить такой файл через интерфейс, чтобы задать его своим ученикам.

⌨️ Консольный режим

Для запуска на локальном или удаленном компьютере без графического интерфейса можно использовать консольную версию.

Для этого надо скачать исходники проекта с GitHub, установить зависимости в окружение python и запустить команду:

python math_test.py --console

Доступен весь функционал, который не требуют HTML-разметки.

Смотри подробное описание в файле README_RU.md

💡 Советы

  • Регулярно занимайтесь по 10–15 минут в день — это улучшает навыки счёта.
  • Используйте «Работу над ошибками» после каждого теста.
  • Для подготовки к контрольным выбирайте ограничение по времени.
  • Если вы учитель, создавайте отдельные профили для учеников и экспортируйте статистику (функция в разработке).
